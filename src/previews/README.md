# Muestras de materiales

Referentes sugeridos: Valentino; soporte de Manuel.

`matambre-preview.ts` y `vacio-preview.ts` ofrecen comparaciones orbitales; `meat-preview-stage.ts` comparte escenario de muestra, renderizador e iluminación.

Abrir `/matambre-preview.html` o `/vacio-preview.html` con Vite iniciado. Los botones crean estados visuales de ejemplo separados de la partida; no certifican el punto térmico.

Desde la raíz: `npm run dev`, `npm test`, `npm run typecheck` y `npm run build`.
