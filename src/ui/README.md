# Interfaz y UX

Referentes sugeridos: Martín y Emily.

`template.ts` define HTML/textos; `style.css` presentación; `hud.ts` actualiza datos y diagnóstico; `target-labels.ts` ayudas de interacción.

`createHud(app, initialMessage)` expone actualización, mensajes, pausa/menú, F3 y callback de inicio. No mover física ni acciones a la interfaz. Probar menú, ayudas, mensajes y F3.

Desde la raíz: `npm run dev`, `npm test`, `npm run typecheck` y `npm run build`.
